# Roadmap

AgentKeel is built in public. Dates are targets, not promises. Track progress on
the [project board](https://github.com/orgs/agentkeel/projects) and in milestones.

| Release | Target | Theme | Highlights |
|---------|--------|-------|-----------|
| **v0.1** | Mar 2027 | Protect and see | TypeScript SDK, MCP proxy, Claude Code hooks, policy engine, approvals (Slack, Telegram, CLI, dashboard), kill switch, budgets and rate limits, hash-chained event store, local dashboard, policy packs, `agentkeel init` |
| **v0.2** | Apr 2027 | Learn and test | Case capture, replay, red-team suite, GitHub Action, Python SDK, OpenAI Agents SDK and LangGraph adapters, signed releases with SBOM |
| **v0.3** | Jul 2027 | Roll out safely | Shadow mode and compare, policy simulation, OpenTelemetry and Langfuse export, MCP HTTP transport |
| **v1.0** | Q4 2027 | Stable for teams | Stable API, Event Schema 1.0, self-hosted server (Postgres), plugin interface 1.0 |

## How to influence the roadmap

- 👍 reactions on issues help us prioritise.
- Ideas go to Discussions → Ideas; larger changes need an RFC issue.
- Design partners test release candidates for a week before each release.
