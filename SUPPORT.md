# Getting help

| You want to… | Go to |
|--------------|-------|
| Ask a question or get setup help | [Discussions → Q&A](https://github.com/agentkeel/agentkeel/discussions/categories/q-a) |
| Share an idea | [Discussions → Ideas](https://github.com/agentkeel/agentkeel/discussions/categories/ideas) |
| Report a bug | [New issue → Bug report](https://github.com/agentkeel/agentkeel/issues/new/choose) |
| Report a security problem | [SECURITY.md](SECURITY.md) (private, never in issues) |
| Read the docs | [agentkeel.github.io](https://agentkeel.github.io) |

Before asking, please run `agentkeel doctor` and include its output (it never
prints secrets).

AgentKeel is maintained by volunteers. We aim to respond within 72 hours.
Commercial support is not offered yet.
